# Bluestock Mutual Fund Analytics Capstone

## Project Overview
This project is an end-to-end mutual fund analytics platform built for the Bluestock capstone project. It covers data ingestion, cleaning, SQLite database creation, EDA, performance analytics, advanced analytics, fund recommendation, and Tableau dashboarding.

## Project Objectives
- Ingest mutual fund datasets
- Clean and validate raw data
- Build SQLite analytical database
- Perform EDA and visualization
- Calculate performance metrics
- Perform advanced risk analytics
- Build Tableau dashboards
- Generate final report and presentation

## Tech Stack
- Python
- Pandas
- NumPy
- Matplotlib
- Seaborn
- SQLite
- SQLAlchemy
- Tableau
- Git/GitHub
